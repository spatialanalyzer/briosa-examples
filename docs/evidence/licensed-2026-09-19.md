# Licensed tutorial validation — September 19, 2026

All four point examples completed successfully against a local licensed
SpatialAnalyzer installation, with explicit maintainer permission to create
the tutorial points. These are observations of the small tutorial workflow,
separate from the [47 portable scenarios](../validation.md).

## Environment

- Windows x64; SpatialAnalyzer and SDK **2026.1.0529.7**.
- Installed Briosa Server **0.7.0**, release source
  `4303a3322074869b35a3f16f9e35484a7bd5c830`.
- Published .NET, TypeScript, and Python client packages **0.2.0**.
- Direct gRPC generated with standard tooling from the verified **0.7.0** protocol.
- .NET SDK **10.0.401**, Node.js **24**, and Python **3.12**.
- One already-running SA instance, initially an empty untitled job containing
  the default collection and world frame. Length unit: **Inches**;
  working frame: **A::WORLD**.

The activated SDK version was runtime-verified. The connected SA version and
communication ownership were checked independently, with a non-sensitive
operator-attestation reference supplied to each launched server. The language
clients discovered the installed server. Direct gRPC used a server started and
connected in Control Center, which reported **Ready for commands** before the run.

## Procedure and results

The actual tutorial programs ran sequentially without source changes or manual
point preparation. Each created its named collection, then P1 and P2 in the
`Points` group. Each read the points and asked SA for their distance.

| Program | Created collection | Result |
| --- | --- | --- |
| .NET client | `BriosaDotnetDemo` | Exit 0; expected coordinates and distance |
| TypeScript client | `BriosaTypeScriptDemo` | Exit 0; expected coordinates and distance |
| Python client | `BriosaPythonDemo` | Exit 0; expected coordinates and distance |
| Direct C# gRPC | `BriosaGrpcDemo` | Exit 0; expected coordinates and distance |

Each printed these tutorial values:

```text
Length unit: Inches
P1: (0.000, 0.000, 0.000)
P2: (3.000, 4.000, 0.000)
Distance: 5.000 Inches
```

After each language-client run, its server, worker, and SDK processes had exited.
The raw gRPC program left the external server and SDK running; they were then
stopped through Control Center. No server, worker, or SDK process remained after
cleanup. The original SA process stayed open throughout. All four demo collections
were visible afterward, and SA still used Inches and A::WORLD. The constructed
points were left in the job for inspection; the job was not saved to disk.

## Scope

This run covers creating a collection, constructing two points in working
coordinates, reading active units and point coordinates, measuring the point-to-point
distance, and the described lifecycle behavior on this exact SA target.
It does not qualify SA 2024, hardware, other construction operations, concurrency,
or repeated execution against existing demo collection names. Failure and uncertain
write outcomes were exercised by the portable suite, not induced in licensed SA.

Raw local diagnostics and machine paths are not included in this record.
